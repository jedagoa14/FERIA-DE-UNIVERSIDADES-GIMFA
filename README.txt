# GIMFA — Feria de Universidades 2026

## Cómo abrir el proyecto
1. Descomprime la carpeta.
2. Abre `index.html` en Google Chrome.
3. Para editarlo, abre la carpeta completa en Visual Studio Code.

## Archivos principales
- `index.html`: estructura y contenido.
- `css/estilos.css`: diseño visual.
- `js/script.js`: cuenta regresiva y menú móvil.
- `img/`: fotografías reales suministradas para el sitio.
